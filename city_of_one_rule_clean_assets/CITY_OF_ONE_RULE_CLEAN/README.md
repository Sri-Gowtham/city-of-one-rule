# CITY OF ONE RULE — Clean Asset Package

## Contents
- `GAME_SPEC/` — complete game specification in Markdown.
- `BACKGROUNDS/` — master background plus earlier variants.
- `BUILDINGS/INDIVIDUAL/` — the individually generated building assets currently available (12).
- `BUILDINGS/SHEETS/` — building reference sheet and the 14-building batch generation.
- `REFERENCES/` — unique supplemental building references.

## Important asset note
The 14-building batch is a single generated sheet. The 14 buildings on that sheet have **not** been separated into 14 individual production PNG files yet. The individual folder therefore contains the 12 separately generated building images currently available.

## Excluded
- Duplicate copies of the same generated image.
- The unrelated FPS image.
