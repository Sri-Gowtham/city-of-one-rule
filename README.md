# City of One Rule

> Change one rule. Watch a city change itself.

A browser-based social simulation where the player controls incentives, not citizens. Full design spec: [GAME_SPEC.md](./GAME_SPEC.md).

## Status

Scaffolding stage: Vite + React + TypeScript project with the isometric city view rendering real building/background art. Rule engine, citizen simulation, and metrics logic are not yet implemented.

## Dev

```
npm install
npm run dev
```

## Assets

Source art lives in `city_of_one_rule_clean_assets/`; the files actually used by the app are copied into `public/assets/`.
